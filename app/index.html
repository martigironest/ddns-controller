¿Qué ocurre al presionar "Actualizar"?

  1. 1 La API en FastAPI recibe el formulario en el endpoint POST /v1/sync.
  2. 2 Ejecuta una llamada HTTP asíncrona segura con httpx hacia la API de DuckDNS.
  3. 3 DuckDNS actualiza sus servidores autoritativos y responde OK.
  4. 4 El backend resuelve el registro DNS para contrastar y renderiza el resultado en la interfaz.
